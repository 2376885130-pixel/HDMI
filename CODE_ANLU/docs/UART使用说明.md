# 星衡双屏 UART 候选版

基线：用户已上板确认正常的 `FPGA_DUAL_HDMI_AUDIO_SECTOR_FIX_20261019`。本副本不更新正式工程，不修改 E 盘。

板载 USB-UART：115200 波特率、8 数据位、无校验、1 停止位、关闭流控。RX F12，TX D12；引脚约束与基线相同。使用串口助手的 ASCII/文本发送模式，并启用 CRLF 行尾。输入的是字符 T1 和实际回车换行，不是字面反斜杠 r/n。

|命令|操作与条件|
|---|---|
|`T1`～`T4`|首页选择月球车、地球观测卫星、月球着陆器、空间望远镜。仍长按 KEY3 进入。主题内部拒绝该命令，回复 `ERR CONTEXT`。|
|`M1`|主题内进入演示；首页拒绝。无需改变 SW3/SW4。|
|`M0`|退出演示；首页无动作并回复 OK。若 SW3/SW4 都下拨，先抑制该组合，任一拨回后才允许再次组合进入。|

每发一条命令，等待 `OK` 或 `ERR ...` 后再发送下一条；期间可能插入完整事件行。重复 M1/M0 不重置模型参数。KEY4 选择参数、KEY2 减少、KEY3 增加，沿用稳定版实际按键方向；没有新增串口参数命令。

通过 UART M1 进入的演示由 M0 退出；纯实体开关进入仍由任一开关拨回退出。长按 KEY1 复位会清空 UART 演示请求。短按 KEY1 基础/进阶切换保持原逻辑。

状态事件：

```text
EV BOOT
EV THEME 1 H
EV THEME 1 T
EV IMAGE 01
EV DEMO 1
EV DEMO 0
```

THEME 的 H/T 分别表示首页/主题内；IMAGE 为全卡 01～32 编号，在画面已提交且匹配请求后发送。BOOT 表示目录非空且首帧已显示，无已同步加载错误。M1/M0 的 OK 表示系统控制器接收命令；副屏仍按原状态邮箱在消隐期提交，事件不表示 HDMI 接收器已物理显示。

事件发送采用一份正在发送的固定快照和各类待发快照，不阻塞音画。同类事件在上一份尚未取走时再次发生，会合并为最新待发状态并报告 `EV OVERFLOW`；不承诺保留突发期间每次事件。命令回复和事件逐行仲裁，不交叉拼接。接收错误、长行、超时或不等待回复的连续发送会返回相应 ERR。

原有 `SUB?`、`SUB=ON/OFF`、`TEXT=...`、`AUDIO?`、`AERR?` 等字幕/诊断命令保留；新增控制只包含六条 T/M 命令。

建议上板顺序：

1. 上电后确认主副屏、图像和音频与基线一致，观察 EV BOOT。
2. 首页发送 T2，确认主题选中卫星，再长按 KEY3 进入，开启 SW1 音频。
3. 发送 M1，按 KEY4/KEY2/KEY3，确认副屏参数变化且主屏讲解持续。
4. 发送 M0，确认退出。再检查实体 SW3+SW4 进入与退出；两开关下拨时发送 M0，确认不会立即重入。
5. 分别检查其他三主题，基础/进阶和 3 秒轮播；最后长按 KEY1 复位，确认恢复首页且演示请求清除。

软件仿真和 TD 检查的范围、结果、资源及时序见 `UART验证报告.md` 与 reports。候选 bit 在用户实机验收前不作为正式发布版。
